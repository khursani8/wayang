# tutorial template

Step-by-step teaching: one teacher host, one step per line, and commands
rendered as a simulated terminal (typing animation plus output lines).
Built for the hyperframes vendor; on remotion the terminal degrades to a
command text card.

Fill order:
1. `characters`: your teacher (name, voice, position, art).
2. `script`: one line per step. Put the command in
   `visual: {type: terminal, command: ..., output: [...]}`.
3. Keep one step per line and end with a recap card.

Theme defaults to slate (dark, terminal-friendly). Commands stay in their
original language; narration is Bahasa Malaysia.
