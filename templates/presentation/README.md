# presentation template

One presenter on the right and big content cards. Scenes act as slide
sections. Pauses are longer so cards get time to breathe.

Fill order is the same as the dialog template. Without character art the
presenter renders as a placeholder box: add PNGs under
`assets/images/<character_id>/` (`mouth_open.png`, `mouth_close.png`) and
set `settings.character.use_images: true`.
